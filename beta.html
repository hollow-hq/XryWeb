rewriting

hollow. beta.

announcement: hollow beta is closing, this was just a preview :>

The bot stays exactly where it is. What's going away is the source code behind it — that gets written again from zero, because the version we have grew past what it can carry.

To be clear: nothing expires and nothing is taken away. The bot you use today keeps working while the code underneath it is replaced.

why

The beta got to the point where almost every command was a patch on top of an earlier patch. It worked, most days. Fixing it properly would have meant rewriting it anyway — so we stopped pretending and started over instead of sinking more time into a codebase we were going to throw away.

The new version is a fresh source code written from zero: same bot, same name, cleaner foundation and commands that are actually built to hold up over time.

what happens to the bot

  • Nothing expires. No invite gets retired, no server gets removed, the bot never leaves.
  • Hollow stays online and in your server exactly as it is, with the same commands and the same setup.
  • Nothing of yours carries over — the new code starts from a clean slate, so treat it as a fresh install.
  • Only the code behind it changes — users should not notice a thing when it does.

what happens to the old code

  • The current beta source code is retired and stops being worked on.
  • It gets kept around for reference, so nothing learned while building it is lost.
  • The replacement is a new codebase, not a patch on the old one.

what stays the same

  • The name, the logo, and the team behind it.
  • The Discord bot itself.
  • The Discord server — it stays open the whole time, beta or not.
  • The feature set you know today. Nothing is being dropped, only rebuilt.

what happens next

  1. The new source code gets written from zero, with the beta still running for everyone.
  2. It gets built and tested, first on a small group of servers.
  3. It replaces the old code under the same bot — no re-invite, no re-setup.
  4. Hollow comes out the other side with documentation and a real changelog this time.

There is no date to write down yet, and we would rather be quiet than wrong. Every update goes out in the Discord server first.

stay in the loop

Join the Discord for progress updates and a say in what gets rebuilt first. Nothing to do on your end — keep using the bot like normal, and come say hi if you want to follow along.
